# Sudoku Wizard

Sudoku Wizard is a polished Python and Pygame Sudoku game with desktop and phone-friendly layouts.

## Highlights

- Easy, Medium, and Hard puzzles
- Classic, Zen, Timed, and Practice game modes
- Notes, erase, undo, hints, and auto-notes tools
- Daily challenges and a progress calendar
- Achievements, coins, streaks, store upgrades, and color auras
- Light and dark themes, sound controls, and persistent player progress
- Responsive controls for both mouse and touch screens

## Run from source

1. Install Python 3.10 or newer.
2. Install Pygame CE:

   ```bash
   pip install pygame-ce
   ```

3. Run the game:

   ```bash
   python main.py
   ```

Keep the `assets` folder next to the Python files.

## Windows release

Download the Windows ZIP from the repository's **Releases** page, extract it, and run `Sudoku Wizard.exe`.

## Data and privacy

Player settings, saved games, and statistics are stored locally on each device and are deliberately excluded from this repository. See [PRIVACY.md](PRIVACY.md).
