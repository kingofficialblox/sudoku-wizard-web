# Sudoku Wizard Support

Support: https://github.com/kingofficialblox/Sudoku/issues

When reporting a problem, include:

- Game version (currently 1.0.0)
- Windows version
- Screen resolution and scaling percentage
- A screenshot and short description of what happened

Player data is stored locally under `%LOCALAPPDATA%\Sudoku Wizard`. Back up this folder before reinstalling Windows or manually resetting progress.

Minimum planned Windows requirements:

- Windows 10 or Windows 11, 64-bit
- 4 GB RAM
- 250 MB available storage
- Display resolution of at least 1280×720
- Mouse or touchpad; touch input is also supported
